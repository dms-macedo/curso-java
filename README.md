Este repositório é o meu registro de estudos e códigos praticados durante o curso [Maratona Java - Virado no Jiraya](https://www.youtube.com/playlist?list=PL62G310vn6nFIsOCC0H-C2infYgwm8SWW), do *DevDojo* (Professor William Suane).

### Navegação

* `exercises`: Contém alguns exercícios e um projeto simples em andamento de uma *loja de games* (pretendo finalizá-lo assim que terminar o curso para colocar tudo em prática).
* `home` e `pasta`: Pastas utilizadas para os exemplos práticos do módulo de manipulação de arquivos (*IO* e *NIO*).
* `src`: Código-fonte de todas as aulas. Acompanhei as explicações do professor William, digitei os códigos por conta própria e fiz minhas próprias alterações para fixar melhor o conteúdo — então a estrutura não está idêntica à do curso.
